# Swiggy Food Delivery Analytics — Excel Dashboard

An interactive Excel dashboard analyzing food delivery order data, built in the style of Swiggy's business, to track orders, revenue, delivery performance, and customer ratings.

## 📊 Dashboard Overview

- **KPI Cards** — Total Orders, Total Revenue, Avg Delivery Time, Avg Rating (formula-driven, auto-updating)
- **Orders by Cuisine** — Which cuisines get the most orders
- **Revenue by City** — City-wise revenue comparison
- **Delivery Time Trends** — Average delivery time analysis
- **Payment Method Split** — Distribution across UPI, Cash, Card, etc.

## 🛠️ Tools & Techniques

- **PivotTables** — Summarizing raw order data (orders by cuisine, revenue by city, etc.)
- **PivotCharts** — Charts linked directly to PivotTables, auto-updating with data changes
- **Excel Formulas** — SUM, AVERAGE, COUNT for real-time KPI calculations
- **Slicers** — Interactive filtering by city, cuisine, and payment method

## 📁 Workbook Structure

The workbook is organized into separate sheets for clarity:
- **Data** — Raw order-level dataset
- **PivotTables** — Summary tables built from the raw data
- **Dashboard** — Final visual report combining KPI cards and PivotCharts

## 📌 Key Insights

- Certain cuisines consistently drive the highest order volume
- A few cities contribute a disproportionate share of total revenue
- UPI is the most preferred payment method among customers

## 💡 Why Excel

This project demonstrates practical Excel skills that are widely used in real business reporting — PivotTables, PivotCharts, and dashboard design — as a complement to Power BI-based analytics.
